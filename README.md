# Patient Intake — Real-Time Form & Staff View

A patient intake form and a staff dashboard that stay in sync in real time.

Tech Stack:

1. Next.js (App Router)
2. TypeScript
3. TailwindCSS
4. Supabase
   (Postgres + Realtime)
5. Vercel

Patient form: `/patient`
Staff view: `/staff`

## Setup Guide

1. Create an account then a project at supabase.com
2. In the SQL editor, copy the code from schema.sql and run it.
3. And then, copy '.env.local.example' to '.env.local' and fill it the values.
4. Run it with 'npm install' and 'npm run dev'
